# Google Play Store listing assets — DOC ONCALL

Upload these in [Play Console](https://play.google.com/console) → your app → **Grow** → **Store presence** → **Main store listing**.

## Required graphics

| File | Use in Play Console | Size |
|------|---------------------|------|
| `01-app-icon-512.png` | App icon | 512 × 512 |
| `02-feature-graphic-1024x500.jpg` (or `.png`) | Feature graphic | 1024 × 500 |
| `03-phone-01-browse-specialties.png` | Phone screenshot 1 | 1080 × 1920 |
| `03-phone-02-treatment-protocols.png` | Phone screenshot 2 | 1080 × 1920 |
| `03-phone-03-drug-guide.png` | Phone screenshot 3 | 1080 × 1920 |
| `03-phone-04-learn-quiz.png` | Phone screenshot 4 | 1080 × 1920 |

Play requires **at least 2** phone screenshots (max 8).
